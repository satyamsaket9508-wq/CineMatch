\# 🎬 CineMatch — Movie Recommendation System



CineMatch is a movie recommendation web app that helps users discover movies similar to the ones they love. It uses \*\*Machine Learning, TF-IDF, and Cosine Similarity\*\* to recommend movies based on their content.



\## ✨ Features



\- 🎯 Recommend movies similar to a selected movie

\- 🔍 Search movies by title

\- 🎭 Filter movies by genre

\- ⭐ Filter movies by rating

\- 🔥 Explore trending and top-rated movies

\- 💎 Discover hidden gems

\- 🧬 View shared text features between similar movies

\- 🎨 Modern dark-themed user interface

\- 🎞️ Optional TMDB integration for posters, cast, and trailers



\## 🛠️ Tech Stack



\- Python

\- Streamlit

\- Pandas and NumPy

\- Scikit-learn

\- TF-IDF

\- Cosine Similarity

\- HTML and CSS

\- TMDB API (optional)



\## 🧠 How It Works



1\. The system loads the movie dataset.

2\. TF-IDF converts movie text into numerical vectors.

3\. Cosine Similarity compares the selected movie with other movies.

4\. The system ranks similar movies and applies the selected filters.

5\. Streamlit displays the recommendations in an interactive interface.



\## 🚀 Run Locally



\*\*1. Clone the repository\*\*



```bash

git clone https://github.com/YOUR-USERNAME/CineMatch.git

cd CineMatch

```



\*\*2. Install the dependencies\*\*



```bash

pip install -r requirements.txt

```



\*\*3. Start the application\*\*



```bash

streamlit run app.py

```



Open the local URL shown in your terminal.



> Make sure the required dataset and model files are present in the project folder.
